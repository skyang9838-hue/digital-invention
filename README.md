# 디지털 발명 교실

찾아가는 과학발명교실 연수(2026.11.18) "디지털과 연계한 발명 수업"용 교실 활동 웹앱.

발명 과정 세 단계를 공식 발명 교재 활동 하나씩으로 체험한다.

| 과정 | 활동 | 교재 |
|---|---|---|
| 문제 발견 | 니즈야! 아이디어를 찾아줘 (생성형 AI 약속·문제 상황 20·프롬프트) | 한국발명진흥회 2026 |
| 아이디어 발상 | 자연은 나의 선생님 (생체 모방 연결 짓기·카드 놀이·오토드로우) | 특허청 「쓱쏙 발명」 2025 |
| 설계·개선 | 배달 음식 포장 용기 (TRIZ 발명 원리 7가지) | 특허청 「국/사/미 속 스마트 발명」 2022 |

정적 사이트(`index.html` · `style.css` · `app.js` · `data.js`). 로그인·서버 없음, 입력은 그 기기 브라우저(localStorage)에만 저장.
문구는 `data.js` 한 곳에 있고 교재 원문 쪽수를 달아 두었다.

로컬: `python -m http.server 8811` → http://localhost:8811
